# El Último Código

Página web interactiva de ciencia ficción, misterio y aventura, hecha con HTML, CSS y JavaScript.

## Descripción
Alex se queda en el laboratorio de informática y encuentra una carpeta desconocida llamada Proyecto 0. Debe recuperar el código perdido antes de que el sistema se bloquee y descubrir quién es NOVA.

## Características principales
- 5 secciones: Portada, El descubrimiento, Las primeras pistas, El código perdido y El último código.
- Menú de navegación y diseño adaptable a computadora y celular.
- Tres interacciones con JavaScript: pista secreta, recuperación de fragmentos de código y final con dos opciones.
- Imágenes propias en formato SVG.
